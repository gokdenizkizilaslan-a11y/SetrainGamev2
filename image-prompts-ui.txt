================================================================
SETRA GAME - UI & BACKGROUND PROMPTS (KREA2)
================================================================
HOW TO USE:
- Buttons: 2 prompts = 2 GRID images (SQUARE 1:1). Generate, cut
  top-left to bottom-right, save each cell to its path.
  Button icons show at 42x42px rounded squares in game — bold,
  centered, instantly readable emblems. They sit on a dark card,
  so bright subjects with glowing edges work best.
- Backgrounds: 1 prompt = 1 image (LANDSCAPE 16:9, 1920x1080).
  The game shows them full-screen COVER behind panels and cards.
  GAME FRAMING (important): menus, cards and text sit CENTER and
  BOTTOM of the screen — keep the busy detail in the TOP half and
  the edges, keep the center-bottom calm and dark so text stays
  readable. NEVER paint words, letters or signs with text.
- After saving files, set any EMPTY paths in content.js -> images
  (buttons + town + combat floors, listed per prompt), then restart.
----------------------------------------------------------------

visible brushwork, cinematic volumetric light, no text, no letters,
no watermarks, wordless composition"
