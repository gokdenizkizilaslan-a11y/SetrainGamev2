================================================================
SETRA GAME - IMAGE PROMPTS (KREA2)
================================================================
HOW TO USE:
- Characters: 1 prompt = 1 image. Save to the file path shown.
  Recommended KREA2: PORTRAIT aspect (3:4 or 2:3, like existing art),
  painterly splash-art style.
  GAME FRAMING (important): the card shows the image full-bleed with
  the name text over the BOTTOM, and the in-game portrait crops a
  CIRCLE from the center. So paint the FACE slightly above center,
  fully lit and fully in frame.
- Skill icons: 1 prompt = 1 GRID image. Generate, then cut in order
  (top-left to bottom-right) and save each cell to its file path.
  Recommended KREA2: SQUARE 1:1 aspect, wordless emblem-style icons.
- IN CELLS write only the skill NAME (no .png, no path): each cell
  says which box (Cell 1, Cell 2...) and what must be inside it.
- 3x3 BREAKS? Use image-prompts-2x2.txt — every 3x3 here is
  pre-split into 2x2 chunks there (same art, same names).
- Only image files are added, then the game restarts.
----------------------------------------------------------------
CHARACTER STYLE (same world as warrior.webp, painted as LoL SPLASH ART):
painterly splash art with visible brushwork, dynamic cinematic light
with a warm key light and a cool rim light, rich yet muted
oil-paint colors, vertical half-body composition showing head,
shoulders and torso, face painted slightly above image center.
COHESION (hepsi benzer): same painterly medium, same medieval-town
world, same muted gold-grey palette family, soft daylight base.
VARIETY (hepsi farklı): every portrait owns its pose, gaze direction,
lighting mood and background corner — 3/4 views, over-shoulder
glances, gazes to the left, right or sky. Each face carries its own
expression and story.
GAME RULES: the full face stays lit, open and inside the frame at
all times — open helmets or pushed-back hoods only, clear eyes,
complete head with space around it.
EVERY hero: attractive aesthetic face with real skin texture, pores
and small natural flaws, clean-shaven smooth jaw, naturally
asymmetric features with handmade character.
CRAFT DETAILS: tangible materials (scarred steel, worn leather,
frayed cloth, chipped paint), a single directing light source per
portrait, well-formed hands with correct fingers, clean wordless
composition. Each prompt states GENDER first, then exact HAIR
(length + type + color), HEIGHT and BODY TYPE, fully specified in every prompt.
- Lv20: seasoned fighter energy, detailed worn gear, calm intent.
- Lv40: EPIC ascended presence, luminous aura and legendary
  filigreed armor, clearly a full tier above the base form.
