==================================================================
SETRA - PET GORSEL PROMPTLARI (KREA2)
101 pet portresi + otomatik dosya isimlendirme
==================================================================

HEDEF KLASOR : public/images/pets/
DOSYA ADI    : content.js -> pets[].id + ".png"
BOYUT        : 256x256 veya 512x512 kare (PNG, seffaf onerilir).
KESIM SIRASI : sol-ust = cell1, sonra soldan saga, satir satir.
EVRELER      : Baby = <id>.png, Young = <id>_young.png,
               Adult = <id>_adult.png. Sadece <id>.png koyarsan
               tum evreler onu kullanir; oyun bozulmaz.

NASIL KULLANILIR:
  1) Grid promptunu KREA'ya aynen yapistir, kare gorsel uret.
  2) Gorseli MAP'teki hucre sirasina gore kes.
  3) Her parcayi MAP'te yazan dosya adiyla kaydet.
  4) Hucre etiketleri sadece sana hangi petin nerede oldugunu soyler;
     gorsele yazi yazdirma (wordless).

BASE STYLE (her promptun icinde zaten var, ayrica ekleme):
"painterly storybook-realism creature portraits, one companion beast per cell in a clean GRID with thin dark gaps on a dark slate background, beast centered and front-facing with expressive eyes, soft round vignette backdrop tinted by element (fire ember orange, water deep blue, earth moss brown, lightning yellow white, dark violet black, physical steel grey, frost ice blue, arcane violet, holy gold white, shadow purple grey, nature leaf green), purely visual wordless emblems"

==================================================================
OTOMATIK ISIMLENDIRME KODU (Node.js)
==================================================================
Asagidaki kodu repo kokunde pet-isimleri.js olarak kaydet ve
`node pet-isimleri.js` calistir. content.js'teki siraya gore
butun gridleri ve dosya adlarini otomatik yazar. Boylece isim
uydurman gerekmez; kod her zaman content.js ile ayni kalir.

```js
// node pet-isimleri.js
const fs = require("fs");
const { CONTENT } = require("./content.js");
const pets = CONTENT.pets || [];
const lines = [];
for (let i = 0; i < pets.length; i += 9) {
  const grid = Math.floor(i / 9) + 1;
  const chunk = pets.slice(i, i + 9);
  const cols = chunk.length <= 2 ? chunk.length : 3;
  const rows = Math.ceil(chunk.length / cols);
  lines.push(`\n--- GRID P${grid} | ${rows}x${cols} | ${chunk.length} pet ---`);
  chunk.forEach((p, j) => {
    lines.push(`cell${j + 1} -> ${p.id}.png   // ${p.name} (${p.element})`);
  });
}
const text = lines.join("\n");
console.log(text);
fs.writeFileSync("pet-isimleri.txt", text + "\n", "utf8");
```
