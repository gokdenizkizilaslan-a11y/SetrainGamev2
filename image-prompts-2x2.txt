================================================================
SETRA GAME - 2x2 FALLBACK GRIDS (KREA2)
================================================================
WHEN TO USE: if Krea breaks the big 3x3 grids (bleeding, merged or
half-cut cells), generate THESE small grids instead. Same art, same
names, same save paths — only the canvas is smaller (max 4 icons).
One chunk = one image. Cut top-left to bottom-right, save each cell
as <name>.png into public/images/skills/ (skill chunks) or
public/images/items/ (item chunks).
KREA2: always SQUARE 1:1 aspect.
IN CELLS only the NAME is written (no .png, no path), numbered in
order — Krea puts them into the boxes by itself.
BASE STYLES: skill chunks use the skill base style, item chunks the
item base style from the main files.
Grids already 2x2 / 1x2 / single in the main files (UB1, UB2, W6,
W7, H2, H3, A2, A3, L2, R2, C2, M4, M5, M6, K2, O1-O4, E2, S17,
S18) need no fallback — generate them as written.
================================================================
